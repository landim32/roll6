# Data Model: Instâncias de NPC no mapa

## MapNpc (`map_npcs`, existing, changed)

| Field | Type | Rule |
|---|---|---|
| current_move | `integer not null` | Deslocamento of this instance (≥ 0, no maximum). Starts at `npcs.move` (`FromNpc`); migration backfills from `npcs.move`. Changed by `Update(currentMove)` (null = keep). `FollowMoveAsync(npcId, old, new)` moves the active instances still at `old`. |
| removed_at | `timestamp without time zone null` | Soft removal (050): set when the instance leaves the map; the piece is deleted, the turn entries stay. Removed rows are skipped by map/campaign listings and counts, returned by id reads (names of old entries), refused by update/delete (404). |

Existing: `name` (required ≤ 260, generated by `MapNpc.NextName` on creation, editable), `current_life`, `current_energy` (≤ the NPC's totals, may be ≤ 0), `status`, `posture`.

### Name generation (pure)

`MapNpc.NextName(npcName, namesInUse)`:
- `namesInUse` = names of the **active** instances of the same NPC **on the same map**.
- Returns `npcName` when not in use; else `"{npcName} {N}"` for the smallest `N ≥ 2` not in use.
- The base is cut so the result is ≤ 260 characters.

### Transitions

- Created → active, piece placed, name generated.
- Edited (name, vitals, move, status, posture) → `CharacterUpdate` turn entry with the diff (keys `name`, `currentLife`, `currentEnergy`, `currentMove`, `status`, `posture`).
- Removed from the map → `removed_at = now`, piece deleted, turn entries kept and still named after it.
- NPC removed from the campaign → every active instance of it on the campaign's maps is removed as above.
- Library NPC deleted (only when in no campaign) → its turn entries and its removed instances are hard-deleted.

## CampaignNpcInfo (DTO, changed)

`mapNpcCount`: active instances of the NPC across the campaign's maps (for the "Retirar da campanha" confirmation).

## MapNpcInfo / MapTokenInfo (DTOs, changed)

- `MapNpcInfo.currentMove`.
- `MapTokenInfo.move` of an NPC piece = the instance's `currentMove` (was the NPC's `move`).
