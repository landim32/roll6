# Quickstart: Editor de imagem no gerador (100)

```bash
cd frontend && npm run lint && npm test && npm run build
```

1. Biblioteca › Mapas › Gerador, generate (or open an own map) so a version is on the stage.
2. "Editar" → Pincel: pick a colour with the conta-gotas, size 30, paint; Ctrl+Z / Ctrl+Y.
3. Clonar: Alt+click on a clean floor, paint over a stain → the floor texture covers it.
4. Cortar: shrink the rectangle, confirm → dimensions change; Girar 90° → width/height swap; Espelhar.
5. Aplicar → the strip shows "v{n} · editada de v{m}"; the previous version is unchanged.
6. Salvar → the suggested grid follows the new size; or send a request → the edited version is the base image.
7. Phone: brush with a finger, "Origem" + tap for the clone, pinch to zoom.
